Customer questionnaires

A big customer has sent a security questionnaire. Where do you start?

Pick one question about who can see customer files. Check the access list for the folder where you keep them.

  • Multi-factor authentication (MFA): an extra sign-in check for email and key accounts.
  • Access: only the people who need customer information can reach it.
  • Backups: important files can be restored if something goes wrong.
  • Patching: work computers and software receive security updates.
