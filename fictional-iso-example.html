Fictional example

ISO 27001 readiness self-assessment

Imagine a costume library run by volunteers. This example follows one booking list from a readiness check to a board decision. All the details are made up.

Readiness view

Scope. Two coordinators send a weekly list of costume deliveries to the volunteers on duty. Each entry includes a hirer’s phone number.

Gap found. A volunteer who finished last month was still on the mailing list. The coordinator removed the address, but nobody had been checking the list when the roster changed.

Statement of Applicability

A.5.18 · Who gets the bookings email. This control applies because only volunteers on the current roster need the hirers’ contact details.

Evidence and next step. The coordinator kept a dated copy of the corrected list. A second volunteer will compare it with the roster before the next mailing.

Board summary

One former volunteer received booking details after their last shift. The address has been removed. Another roster change could cause the same problem.

Decision requested. Give the roster lead ten minutes at each changeover to arrange a second check. At the next meeting, ask to see the first two dated checks.
