# Security

Do not disclose suspected credentials, private account details or customer data in public issues. Use the security contact published in `.well-known/security.txt` or the owner's established private reporting channel. This candidate has not configured GitHub private vulnerability reporting.

Protect identity, authorization, tenant boundaries, confidential data, integrity, bounded public side effects, costs and recovery. Critical/high reachable issues, credential exposure or credible customer-data/integrity risks block the affected capability. Preserve deterministic enforcement and least privilege.

Public fork CI must remain secretless with read-only repository permissions. No production OpenAI key or cloud identity belongs in this pipeline. Required application, dependency and native database checks must remain enforceable before migration. Production evidence and the private release controller stay separate until an explicitly reviewed migration is accepted.
