## Witness record (one synthetic run per candidate)

Record candidate SHA, environment, flag state, operator role, synthetic tenant/org aliases, test time and result for each gate. For each negative case, compare before/after counts in authorised test evidence. For retries, correlate a single request with one task and one delivery intent, then separately verify delivery outcome. For manual transitions, capture the proposal version, acceptance, invoice reference and independent activation witness using synthetic identifiers only. Keep evidence in the access-controlled release record, not in a public issue or this worksheet. Mark any missing witness **not tested**; passing the routing helper or database tests alone does not qualify the journey.
